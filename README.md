# ❤️ Heart Disease Prediction using Machine Learning

## 📌 Project Overview
This project predicts whether a person has heart disease or not using Machine Learning techniques.  
It uses patient health data such as age, cholesterol, blood pressure, etc.

---

## 🎯 Objective
To build a classification model that can predict the presence of heart disease based on medical attributes.

---

## 📊 Dataset
- Dataset: UCI Heart Disease Dataset
- Format: CSV (heart.csv)

### Features:
- age → Age of the patient  
- sex → Gender (1 = Male, 0 = Female)  
- cp → Chest pain type  
- trestbps → Resting blood pressure  
- chol → Cholesterol level  
- thalach → Maximum heart rate  
- target → Output (0 = No Disease, 1 = Disease)  

---

## 🧠 Machine Learning Model
- Algorithm: Logistic Regression  
- Type: Classification
